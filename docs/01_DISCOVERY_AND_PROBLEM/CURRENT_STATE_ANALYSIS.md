# Current State Analysis

## Externally verified

1. Healthkathon 2026 explicitly identifies six employer-risk modes.
2. Employer obligations include worker registration, accurate worker/wage data, reporting changes, and contribution payment.
3. BPJS Kesehatan publicly exposes e-Dabu Badan Usaha as an employer-facing service.
4. BPJS Kesehatan publicly highlights employer-compliance initiatives, including OSS ecosystem integration.
5. Real participant JKN data cannot be used for the competition prototype without authorization.

## Unknown internal state

The project does not currently possess authoritative evidence for:

- which BPJS unit performs employer-risk review;
- the exact end-to-end current workflow;
- case volumes and review capacity;
- existing internal risk scoring or analytics;
- actual data schemas and cross-agency data access;
- average resolution time or recurrence rate;
- false-positive rate of existing controls.

## Consequence for design

No Phase B requirement may be justified by statements such as "the current BPJS process is manual/slow/fragmented" unless a source is added. Requirements must instead trace to:

- official risk definitions;
- formal obligations;
- explicit competition requirements;
- clearly labeled prototype hypotheses.
