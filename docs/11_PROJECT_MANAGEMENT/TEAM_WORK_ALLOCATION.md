# Team Work Allocation

| Area | Owner | Accountability |
|---|---|---|
| Synthetic data, generation, validation, EDA, data card | Lintang | Data workstream |
| Baseline, model selection, HGB/alternatives, anomaly model, evaluation, calibration, model card | Haidir | ML workstream |
| Product, architecture, backend, decision/rule engine, integration, frontend/dashboard, testing, deployment, governance | Panji | System/Product lead |

## Handoff
Lintang → Haidir: processed dataset, feature definitions, ground truth, split, manifest, data card.

Haidir → Panji: model artifact, feature order, version, thresholds, metrics, model card, inference contract.

Semua perubahan kontrak lintas workstream setelah freeze wajib melalui change control.
